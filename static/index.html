Max Pain Explanation

Computed from current CE and PE open interest across available strikes.

⌖
What does Max Pain mean?

For each possible settlement strike, the calculation estimates aggregate intrinsic payout using current open interest. The strike with the lowest calculated payout is shown as Max Pain. It is an analytical reference, not a forecast of expiry settlement.
